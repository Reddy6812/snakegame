# Snake Game

An enhanced Snake game built with JavaScript, HTML5 Canvas, and CSS, featuring smooth rounded graphics, dynamic gradients, and realistic collisions. Navigate the snake to eat food and grow longer. Colliding with borders or yourself ends the game.

## Live Demo

Play the game live: [https://reddy6812.github.io/snakegame/](https://reddy6812.github.io/snakegame/index.html)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Reddy6812/snakegame.git
   ```
2. Navigate to the project directory:
   ```bash
   cd snakegame
   ```
3. Open `index.html` in your browser or serve with a local HTTP server:
   ```bash
   npx serve . # or any static server
   ```

## Controls

- Arrow Keys: Change snake direction
- Restart button: Restart the game
